## はじめに

これはサンプルのブログ記事です。MDX 形式で記述されており、Markdown の中に JSX コンポーネントを埋め込むことができます。

## 機能

- **Markdown 記法**がそのまま使えます
- コードブロックも対応しています
- リストや見出しなど、一般的な Markdown 記法はすべてサポートされています

## コード例

```javascript
const greeting = "Hello, World!";
console.log(greeting);
```

## まとめ

`content/blog/` ディレクトリに `.mdx` ファイルを追加するだけで、新しい記事を公開できます。
